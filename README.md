# SE - Calcolo materiali nave

Strumento per **Space Engineers 1** (Python 3, solo libreria standard) che legge una blueprint (`bp.sbc`) e calcola componenti, lingotti e minerali necessari per costruirla, tenendo conto delle mod del mondo o del server.

## Funzioni
- **Calcolo materiali**: modalità Vanilla, Mondo salvato o Server online (mod lette dai log del gioco, solo per il calcolo).
- **Mondo di test locale**: crea un mondo locale da un modello del gioco con le mod e i parametri di un server, per provare le navi.

## Avvio
```
python se_gui.py
```
oppure doppio clic su `se_gui.pyw`. Uso da riga di comando: `python se_calc.py --help`.

Istruzioni complete in [LEGGIMI.txt](LEGGIMI.txt), note tecniche in [NOTE_PROGETTO.md](NOTE_PROGETTO.md).
